**IconButton** — a square control wrapping a single icon for toolbars, card menus, and compact actions; always pass `label` for accessibility.

```jsx
<IconButton label="Settings"><i data-lucide="settings" /></IconButton>
<IconButton variant="solid" label="Refresh"><i data-lucide="refresh-cw" /></IconButton>
<IconButton variant="accent" label="Add device"><i data-lucide="plus" /></IconButton>
```

Variants: `ghost` (default), `solid` (panel fill), `accent` (solar fill). Sizes `sm | md | lg`.
