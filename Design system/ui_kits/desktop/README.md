# Power — Desktop dashboard (UI kit)

A high-fidelity recreation of the **Power** desktop control center. Dark control-room
aesthetic, electric-green solar accent, mono digital readouts, animated energy flow.

## Run
Open `index.html`. It loads React + Babel + Lucide + the compiled design-system
bundle (`../../_ds_bundle.js`), then mounts the app. The bundle is generated by the
compiler — if it 404s, the design system hasn't compiled yet.

## Screens (click the sidebar to switch)
- **Overview** — live `EnergyFlow`, live readouts, battery gauge, KPI row, day chart.
- **Statistics** — production-vs-consumption bars, KPI tiles, per-device breakdown.
- **Devices** — device list + detail panel with controls (select a row to inspect).
- **Optimization** — automation rules (toggle Switches), 24h tariff strip, battery strategy.

## Files
- `index.html` — entry; script load order matters (data → charts → chrome → screens → App).
- `data.js` — mock data + `drawIcons()` helper (re-runs Lucide after React renders). Exposes `window.PWRKit`.
- `charts.jsx` — `AreaChart`, `BarChart` (SVG). Exposes `window.PWRCharts`.
- `Chrome.jsx` — `Sidebar`, `TopBar`.
- `OverviewScreen.jsx`, `StatisticsScreen.jsx`, `DevicesScreen.jsx`, `OptimizationScreen.jsx`.
- `App.jsx` — shell wiring nav + screens.

All UI is built from the design-system components (`window.PowerDesignSystem_138199`):
`Card`, `StatTile`, `RadialGauge`, `EnergyFlow`, `Sparkline`, `ProgressBar`, `Badge`,
`StatusDot`, `Switch`, `Slider`, `Select`, `SegmentedControl`, `Button`, `IconButton`.
